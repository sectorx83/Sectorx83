# Sectorx83® — Independent Digital Works

The personal developer portfolio of **Tyler (@sectorx83)**, built with React, TypeScript, and Vite.

The visual direction is an editorial, studio-style portfolio: oversized typography, restrained oxblood accents, tactile project artwork, clear project indexing, and purposeful motion. The identity mark is **[sx⁸³]®**.

## Featured work

- **D3X8** — experimental 64-bit x86_64 operating system and custom desktop environment.
- **Flux Agent** — completed local-first AI agent and automation CLI.
- **Cathedral** — open computing laboratory; Phase 4 desktop studio and experiment tooling is in progress.
- **Gravity** — adaptive computational runtime; Phase 2 evolution engine verified on `main`.
- **EDITH X1** — live multi-user AI assistant platform.

Each project has an individual detail page under `/projects/<project>/`. Project statuses distinguish completed work from active development and documented limitations.

## Development

Requires Node.js 20+.

    npm install
    npm run dev
    npm run build
    npm run preview
