# Tyler — Developer Portfolio

Personal portfolio for **Tyler (@sectorx83)**, built with React, TypeScript, and Vite.

## Featured work

- **D3X8** — experimental 64-bit x86_64 operating system and custom desktop environment.
- **Flux Agent** — completed local-first AI agent and automation CLI.
- **Cathedral** — open computing laboratory; Phase 4 desktop studio and ecosystem work is in progress.
- **Gravity** — adaptive computational runtime; Phase 2 evolution engine verified on `main`.
- **EDITH X1** — live multi-user AI assistant platform.

Each featured project has an individual detail page under `/projects/<project>/` and a matching documentation directory under `projects/`. Project statuses distinguish completed work from active development and documented limitations.

## Current focus

- **Cathedral:** Phase 4 desktop studio, experiment controls, and validation.
- **D3X8:** experimental OS development, including kernel, memory, and desktop stability.
- **Gravity:** Phase 2 is complete against its documented exit criteria; formatting, Clippy, workspace tests, documentation, and both CLI demonstrations pass on `main`.
