# EDITH X1

**Status:** Live application  
**Category:** AI / Assistant platform  
**Repository:** https://github.com/sectorx83/edithx1  
**Live app:** https://www.edithx1.vercel.app

EDITH X1 is a multi-user AI assistant web application built with React, TypeScript, TanStack Start, Vite, and Supabase.

## Current capabilities

- AI chat with automatic anonymous sessions.
- Voice input and local speech playback.
- Configurable assistant behavior.
- EDITH NETWORK execution layer.
- Groq-backed chat using server-side credentials.

## Setup

Use the upstream repository's Setup Guide for Supabase configuration, Groq setup, local development, testing, and deployment. Never expose provider credentials through client-side environment variables.
